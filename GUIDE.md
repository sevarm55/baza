# Справочник Tetrin

Учёт для автомойки. Мойщик записывает машину с телефона, владелец видит
выручку, зарплату, расходы и то, что ему остаётся. Веб (tetrin.pro) и
приложение для iPhone работают с одними данными, разделы одинаковые.

Деньги в драмах, целыми числами. Сутки считаются по часовому поясу бизнеса.
Язык интерфейса армянский, есть русский и английский.

---

## 1. Кто чем пользуется

| Роль | Где работает | Что делает |
|---|---|---|
| Мойщик (`staff`) | `/work` | смена, запись машин, свой заработок, сдача наличных |
| Владелец (`owner`) | `/owner` и `/work` | весь бизнес плюс может мыть и записывать сам |
| Владелец платформы | `/admin` | подписки, платежи, поддержка, журнал |

Один телефон принадлежит одному человеку. У человека может быть несколько
филиалов, и роль на каждом своя.

---

## 2. Вход и регистрация

**Регистрация.** Кнопка «Начать» на витрине: номер телефона, код из SMS,
название мойки. Прайс, термины и роли приходят заполненными.

**Вход владельца.** Номер телефона плюс код из SMS. Если в профиле создан
постоянный код доступа (6 цифр), можно входить им и без SMS.

**Вход сотрудника.** Номер телефона плюс код доступа, который выдал владелец.
SMS сотруднику не приходит.

**Незнакомое устройство.** Продукт попросит код из SMS дополнительно. Так
происходит только у того, чей номер подтверждён и у кого уже есть знакомые
устройства: первое устройство запоминается молча.

**Забыт код доступа.** Владелец восстанавливает его по SMS («Забыли код
доступа?»). Сотруднику новый код выдаёт владелец: Сотрудники → карточка →
«Выдать новый код доступа».

Код из SMS: 6 цифр, живёт 10 минут, новый гасит предыдущий. Число попыток и
повторных отправок ограничено на сервере.

---

## 3. Первый запуск владельца

Пять шагов, все на настоящих данных: прайс, один расход, работник, взгляд на
продукт глазами работника, первая машина. Любой шаг можно отложить кнопкой
«Настроить позже», сценарий продолжится с того же места.

---

## 4. Смена мойщика (`/work`)

1. **Начать смену.** Пока смена не открыта, записывать нельзя.
2. **Записать машину.** Номер → услуга (и класс, если классы включены) →
   оплата: наличные, карта, перевод, абонемент. Отдельным полем можно дать
   скидку, тогда в записи останутся обе цены.
3. **Совместная мойка.** Переключатель «Вместе с коллегами» появляется, если
   владелец задал процент команды. Отметить можно только тех, кто сейчас на
   смене, до 8 человек. Себя отмечать не нужно.
4. **Наверху экрана.** Заработок за сегодня, сумма работ, сколько наличных
   предстоит сдать.
5. **Завершить смену.** В окне закрытия видно, сколько наличных набралось, и
   поле «Сдаю наличными». Расхождение владелец увидит у себя.

Знакомый клиент узнаётся во время набора номера: сколько раз был, когда и на
какую сумму.

**Отмена.** Свою запись мойщик отменяет крестиком, счётчик пересчитывается
сразу. Чужие записи он не видит. Исправить запись нельзя, только отменить и
записать заново.

**Без связи.** Запись всегда сначала ложится в телефон и помечается «Ждёт
связи», отправка догоняет сама. Повторная досылка не создаёт вторую машину.
Отменить запись из очереди можно только после отправки.

**Забытая смена** закрывается сама в 20:00 по времени бизнеса, вчерашняя
закрывается началом суток.

## 5. Кабинет владельца

| Раздел | Адрес | О чём |
|---|---|---|
| Сегодня | `/owner` | сводка дня или месяца |
| Календарь | `/owner/calendar` | месяц целиком, переход в день |
| Смена | `/work` | владелец записывает машины сам |
| Клиенты | `/owner/clients` | база машин и визитов |
| Услуги | `/owner/services` | прайс и классы |
| Сотрудники | `/owner/staff` | люди, проценты, коды доступа |
| Абонементы | `/owner/passes` | только при `PASSES_ENABLED=1` |
| Зарплаты | `/owner/payroll` | расчёты и выплаты |
| Расходы | `/owner/expenses` | аренда, химия, разовые траты |
| Отчёты | `/owner/reports` | аналитика за любой период |
| Настройки | `/owner/settings` | бизнес, выгрузка, удаление |
| Моя страница | `/owner/profile` | вход, устройства, вид |
| Филиалы | `/owner/points` | переключение между точками |
| Живая лента | `/owner/activity` | все события с фильтрами |

На телефоне внизу четыре вкладки (Сводка, Смена, Зарплата, Ещё) и круглая
кнопка записи посередине. Остальные разделы лежат в «Ещё».

### Сегодня

Период переключается: Сегодня, Этот месяц, Прошлый месяц. Сверху то, что
остаётся владельцу, под ним выручка, зарплата и расходы, дальше ход дня
графиком, кто сейчас на смене, чем платили, и журнал записей. Любую запись
можно отменить прямо из журнала.

Блок «Внимание» загорается сам: скидки за период, отменённые записи,
расхождение наличных по смене, никого нет на смене.

### Календарь и день

Сетка месяца со столбиками выручки. Нажатие открывает день: кто стоял на
смене, сколько наличных ожидалось и сколько человек сдал, вся работа за день.
Это единственное место, где видна сдача наличных по каждой смене.

### Клиенты

Машина попадает в базу сама после первой мойки. Видно визиты, потраченную
сумму, привычки (что берёт чаще, чем платит, кто обслуживает), историю.
Клиента можно подписать именем и телефоном и позвонить ему в одно нажатие.
Кто не приезжал больше 21 дня, попадает в «Давно не были».

### Услуги

Цена меняется только на будущее: вчерашняя выручка и зарплата не
пересчитываются. Убранная услуга уходит из прайса, а прошлые записи с ней
остаются. Классы (джип, седан) включаются от двух штук и дают каждой услуге
свою цену на каждый класс.

### Сотрудники

Имя, телефон, код доступа и процент. Процент действует на новые записи,
начисленное не меняется. Отключение сотрудника закрывает ему вход сразу, а
записи и история выплат остаются. Здесь же задаётся процент совместной мойки:
это процент на всю бригаду, он делится поровну между участниками.

### Зарплаты

Две вкладки: «К выплате» и «История». Расчёт разложен по дням. Выплатить можно
одному или нескольким сразу, одним событием. Считается от момента последней
выплаты, поэтому дважды заплатить за одну работу нельзя.

### Расходы

Разовый расход лежит в своём дне. Ежемесячный (аренда, электричество)
распределяется по дням месяца и начисляется сам. Правка суммы действует с
сегодняшнего дня, прошедшие дни не переписываются.

### Отчёты

Период: сегодня, неделя, месяц, прошлый месяц или свои даты. Сравнение с
предыдущим отрезком той же длины. Охват: текущий филиал, все филиалы, либо
сравнение филиалов между собой. Вкладки: Обзор, Финансы, Работа, Команда.
Внутри динамика, машины, средний чек, загрузка по дням и часам, услуги,
способы оплаты, расходы по статьям, команда. Выгрузка в CSV за выбранный
период.

### Настройки и профиль

Настройки: название бизнеса, выгрузка записей за 30 дней в Excel, удаление
бизнеса (подтверждается кодом доступа или кодом из SMS). Выгрузка работает и на
других экранах: в отчётах она отдаёт выбранный период, в «Ещё» всю историю.

Моя страница: имя, телефон, код доступа (создать, изменить, удалить), смена
номера, список устройств с возможностью закрыть чужой вход, уведомление о
каждой машине, «запомнить этот аккаунт», язык, тема, состояние подписки.

### Колокольчик

Два повода: клиенты давно не приезжали и пора выплатить зарплату (проходит
7 дней с последней выплаты). Повод можно отложить на неделю, он вернётся,
если ничего не изменилось.

---

## 6. Как считаются деньги

- **Выручка** это оплаченные на месте записи (наличные, карта, перевод) плюс
  проданные абонементы.
- **Списание абонемента** выручки не создаёт: деньги пришли при продаже.
  Мойщик при этом получает свой процент от номинала одной мойки.
- **Зарплата** считается по проценту, записанному в момент записи. Совместная
  мойка: фонд машины делится поровну, остаток в драмах достаётся тому, кто
  записал.
- **Вам остаётся** это выручка минус зарплата минус расходы.
- **Средний чек** считается только по оплаченным на месте, чтобы один
  абонемент не раздувал картину.

---

## 7. Правила, которые обойти нельзя

1. Не открыл смену, значит не записываешь.
2. Запись не правится, только отменяется.
3. Цена, название услуги и процент фиксируются снимком внутри записи.
4. Способа оплаты «в долг» нет.
5. Мойщик видит только свою работу и свои деньги.
6. Бизнесы не видят данные друг друга ни в чём.

## 8. Приложение для iPhone

Те же разделы и те же числа. Своё в приложении:

- сканер номера камерой с поправкой на путаницу букв и цифр;
- вход по Face ID после первого входа;
- Live Activity и Dynamic Island с ходом открытой смены;
- пуши: открытие смены, закрытие смены со сдачей наличных, каждая машина
  (включается в профиле);
- досылка записей из очереди, когда приложение закрыто.

Новый филиал в приложении не заводится: это делается на сайте.

## 9. Подписка и доступ

6 дней бесплатно, дальше 15 000 ֏ в месяц за каждый филиал. Оплата проходит
вне приложения, факт оплаты отмечается вручную.

| Состояние | Что значит | Что доступно |
|---|---|---|
| `trial` | идёт пробный срок | всё |
| `active` | оплачено | всё |
| `unpaid` | новый филиал ещё не оплачивали | стена «Ждёт оплаты» |
| `expired` | срок вышел | стена, выгрузка и удаление работают |
| `blocked` | закрыт платформой | стена, данные сохранены |

Напоминание появляется за 5 дней до конца. Просрочка закрывает и кабинет
владельца, и запись у мойщика: мойка не оплачена, значит мойки в продукте нет.
Забрать свои данные можно в любом состоянии.

Отметить оплату: `npm run activate -- +37477111222 3` либо из админки.
Подвинуть пробный срок: `npm run trial -- +37477111222 7`.

## 10. Вид и язык

Язык (армянский, русский, английский) и тема переключаются в меню аккаунта и в
профиле, выбор помнится год. На телефоне в том же меню выбирается вид нижней
полосы вкладок: Грейп, Светлая, С подписями, Графит, Лайм.

---

## 11. Админка платформы (`/admin`)

Вход отдельный, логин и пароль живут в окружении сервера (`ADMIN_LOGIN` плюс
`ADMIN_PASSWORD_HASH` или `ADMIN_PASSWORD`), в базе их нет. Сессия 12 часов и закрывается после
2 часов простоя.

Разделы: Обзор (сколько бизнесов, кто жив, деньги месяца, конверсия), Бизнесы,
Пользователи, Подписки, Платежи, Журнал действий, Поддержка, Доступ.

## 12. Разработка и эксплуатация

```bash
npm run dev
```

| Команда | Что делает |
|---|---|
| `npm run smoke` | слой данных на чистой базе в памяти |
| `npm run e2e` | сквозной прогон по живому серверу |
| `npm run security` | проверки того, что не должно работать |
| `npm run typecheck` | типы |
| `npm run db:up` / `db:fresh` | локальный Postgres в Docker, пересборка с демо |
| `npm run db:migrate` | миграции (на сервере отдельным шагом) |
| `npm run activate` / `trial` | подписка и пробный срок |
| `npm run seed:carwash` | наполнить мойку данными |

База выбирается сама: с `DATABASE_URL` настоящий Postgres, без него PGlite в
`.data/`. Ручные сценарии проверки лежат в [TESTING.md](TESTING.md).

**Выкат в бой:**

```bash
ssh contabo "cd /opt/bazis && bash infra/deploy.sh"
```

**Тестовый стенд** `test.tetrin.pro`, ветка `test`, отдельная база, SMS не
уходят и код печатается в лог контейнера:

```bash
ssh contabo "cd /opt/bazis-test && bash infra/deploy-test.sh"
```

**По расписанию на сервере:** закрытие забытых смен (раз в час), утреннее
напоминание о кончающемся сроке, наполнение демо-бизнеса и витринной мойки.

**Демо:** `scripts/demo-account.ts` готовит бизнес для ревью App Store,
`scripts/demo-showcase.ts` витринную мойку с классами, бригадами и абонементами
для показа на встрече.

**Переменные окружения** перечислены в [README.md](README.md). Ключевые:
`DATABASE_URL`, `SESSION_SECRET`, `SMS_*`, `CRON_SECRET`, `PASSES_ENABLED=1`
(абонементы), `BILLING_ENABLED=0` (показ без тикающего срока), `STAGING=1`
(только стенд).
