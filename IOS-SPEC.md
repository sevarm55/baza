# Спецификация редизайна: «Այսօր» (владелец) и «Հերթափոխ» (мойщик)

---

## 1. Тема: светлое приложение на тёмном шве

**Решение: приложение остаётся светлым. Тёмным становится только фон-подложка — шов между плитками.**

Почему не тёмное, при том что референс тёмный:

1. **Физика солнца.** Отражённая яркость экрана складывается с излучаемой. На светлом поле она добавляется к обоим цветам и почти не трогает отношение контрастов; на тёмном поле она добавляется к фону, у которого своей яркости почти нет, — и контраст падает в разы. Мойка на улице, полдень в Ереване. Тёмный экран под солнцем — это экран, на котором не видно ничего, кроме лаймовой кнопки. Ровно это уже записано в слабых местах экрана мойщика.
2. **Мокрый экран.** Капли на стекле рассеивают свет. На тёмном фоне каждая капля становится белым пятном поверх тёмного, то есть шумом с высшим контрастом на экране. На светлом фоне капля почти не видна.
3. **Веб останется светлым.** Тёмное iOS-приложение при светлом сайте — расхождение не только эстетическое: цвет человека, цвет оплаты, лайм и грейп в тёмной версии другие, и владелец, сверяющий телефон с ноутбуком, видит два разных продукта.
4. **DESIGN.md уже решил это для лендинга** (§4): «чистый чёрный на площади страницы читается дырой», тёмный там только шов. Приложение и лендинг сходятся сами собой.

**Что берём из FitPulse, не платя за темноту:**

| Приём референса | Как живёт здесь |
|---|---|
| Тёмное поле | Шов `#1C1C1E` шириной 10pt между плитками и по краю экрана. Тёмного на экране 12–18 % площади, и на нём нет ни одной цифры |
| Фото во всю ширину, уходящее в темноту | Только в состояниях, где нет данных (вход, онбординг, смена до открытия). На рабочих экранах фото нет — см. §5 |
| Стеклянные карточки с обводкой | Только над фотографией и только под закреплёнными органами управления, которые плавают над прокруткой. Со статичных карточек стекло снимается |
| Круглые кнопки-иконки рядами | Аватары людей на смене и иконки способов оплаты. Ряда «пять кружков-действий» нет: у владельца нет пяти действий |
| Белая капсула с чёрным кругом и стрелкой | Главная кнопка мойщика (лайм + чёрный круг) и круг на шве у владельца |
| Дуговой индикатор с рисками | Ровно один на всё приложение: доля наличных в плитке «Վճարումներ» |
| Зелёная точка «идёт сейчас» | Плитка статуса смены и заголовок «Հերթափոխին» |
| Круглые кнопки назад/домой в углах | Не берём: есть таб-бар. Две навигации на экране — одна лишняя |

**Чем платим за это решение:**
- Экран не будет похож на скриншот FitPulse. Он будет похож на лендинг Tetrin — что для продукта важнее.
- Тёмная тема iOS остаётся и требует второго набора значений: шов в тёмной теме темнее плиток, иначе сетка исчезает.
- Появляется новый класс ошибок: **тёмная плитка в светлой теме**. `Brand.good`, `Brand.ink`, `Brand.person()` адаптируются по теме системы, а не по цвету поверхности под текстом. Тёмно-зелёный `#047857` на угольной плитке — невидим. Лечится вторым набором токенов `*OnDark` (§2.1), и это обязательная часть работы, а не деталь.

## 2. Система

### 2.1. Палитра

Марочные цвета не трогаем — они уже в вебе и в базе кода:

```
grapeFill  #6D28D9   grapeMid  #4C1D95   grapeDeep #2E1065
lime       #D7FF00   onLime    #2E1065
```

> Расхождение, которое надо закрыть отдельно: DESIGN.md лендинга объявляет `--violet #7E7CEB` и `--lime #C9F24D`. Это другие цвета. Канон — значения приложения (они в продукте и в вебе), лендинг подтягивается к ним, а не наоборот. Иначе демонстрационный скриншот на сайте не совпадёт с приложением в руке.

**Меняются в `Theme.swift`:**

| Токен | Было | Стало | Зачем |
|---|---|---|---|
| `bg` | `#FAF9FC / #120F1A` | **удалить из роли фона экрана** | Фон экрана больше не заливка, а шов |
| `heroGradient` | `grapeMid → grapeDeep` | `#6D28D9 → #4C1D95`, 160° | `#2E1065` рядом с углём `#1C1C1E` — два тёмных встык, грязь |
| `GlassCard` | `.padding(16).glassEffect(.regular)` | заменить на `Tile` (§2.4) | Стекло на плоском фоне — мутная плашка (DESIGN.md §7) |
| `LimeButton` | radius 22, `.system(size: 17)` | капсула, `@ScaledMetric(relativeTo: .headline)` | Всё нажимаемое — капсула; 17pt не масштабируется |
| `screenBackground()` | `Brand.bg` | `Brand.seam` | — |

**Добавляются:**

```swift
// подложка и плитки                         светлая     тёмная
static let seam      = adaptive(light: 0x1C1C1E, dark: 0x08070C) // шов, поле экрана
static let tile      = adaptive(light: 0xFFFFFF, dark: 0x1A1626) // основная плитка
static let tileSoft  = adaptive(light: 0xF5F4F1, dark: 0x221C33) // вторичная плитка
static let charcoal  = adaptive(light: 0x2A2A2C, dark: 0x2A2436) // служебная тёмная плитка

// текст и знаки НА ТЁМНОМ, независимо от темы системы
static let inkOnDark    = Color.white
static let mutedOnDark  = Color.white.opacity(0.72)
static let faintOnDark  = Color.white.opacity(0.50)
static let goodOnDark   = Color(hex: 0x34D399)
static let warnOnDark   = Color(hex: 0xFBBF24)
static let lineOnDark   = Color.white.opacity(0.14)
static func person(_ name: String, onDark: Bool) -> Color   // onDark → всегда светлый вариант
```

**Правило поверхностей — единственное, которое нельзя нарушать:** цвет текста выбирается по цвету **плитки под ним**, а не по теме системы. Плитка `tile`/`tileSoft` → `ink`/`muted`/`good`/`warn`/`person(name)`. Плитка `charcoal`/`seam`/грейп/фото → `inkOnDark`/`mutedOnDark`/`goodOnDark`/`warnOnDark`/`person(name, onDark: true)`.

Проверенные контрасты (WCAG, sRGB):

| Пара | Контраст |
|---|---|
| `ink #1A1626` на `tile #FFFFFF` | 16 : 1 |
| `muted #56506B` на `tile` | 7.6 : 1 |
| белый на `grapeFill` | 7.7 : 1 |
| белый **0.85** на `grapeFill` | ≈ 5.5 : 1 |
| белый **0.78** на `grapeFill` | 4.9 : 1 — **нижняя граница, ниже нельзя** |
| `onLime` на `lime` | 13 : 1 |
| `warnOnDark` на `charcoal` | ≈ 9 : 1 |
| `good #047857` на `tile` | 5.6 : 1 |

Пропорция на экран: **60 светлых плиток / 20 грейпа / 14 шва и угля / 4 лайма / 2 фото**. Лайм — только действие. Угольной плитки на экране не больше одной, кроме плитки убытка (она и есть та одна).

### 2.2. Шкала кеглей

Пять ролей, ни одной между ними. Все размеры — через `@ScaledMetric`, потому что `Font.system(size:)` игнорирует Dynamic Type, а сейчас в `ios/Tetr` таких вызовов 126.

| Роль | База | Вес / начертание | `relativeTo` | Где |
|---|---|---|---|---|
| `figure` | 52 | `.black`, `.rounded`, `monospacedDigit` | `.largeTitle` | Одно число на плитку. Одна `figure` на экран |
| `figureS` | 30 | `.bold`, `.rounded`, `monospacedDigit` | `.title2` | Число в мелкой плитке и в центре дуги |
| `head` | 20 | `.bold` | `.title3` | Заголовок плитки, итог лестницы, сумма в строке ленты |
| `body` | 15 | `.regular` / `.semibold` | `.subheadline` | Всё остальное |
| `tag` | 11 | `.bold`, трекинг +0.06 | `.caption2` | Ярлык над числом, подпись оси, время в ленте |

```swift
@ScaledMetric(relativeTo: .largeTitle) private var figure: CGFloat = 52
@ScaledMetric(relativeTo: .title2)     private var figureS: CGFloat = 30
@ScaledMetric(relativeTo: .body)       private var pad: CGFloat = 20
@ScaledMetric(relativeTo: .headline)   private var knob: CGFloat = 48
```

Правила:
- **Капса нет нигде.** Армянский капс читается хуже латинского, а весь интерфейс армянский. `tag` держится весом и трекингом, не регистром. Нынешние 11pt капсом с трекингом 1.2 — уходят.
- На `figure` — потолок `.dynamicTypeSize(...DynamicTypeSize.accessibility2)`, `lineLimit(1)`, `minimumScaleFactor(0.6)` **только** при `typeSize.isAccessibilitySize`.
- Каждое меняющееся число: `monospacedDigit()` + `contentTransition(.numericText(value:))` с переданным значением.
- Обе длинные строки под `figure`: `fixedSize(horizontal: false, vertical: true)`.

### 2.3. Сетка, радиусы, отступы

```
шов / поле экрана        10pt   (равны — щит доходит до края)
падинг внутри плитки     20pt   (вдвое больше шва: воздух внутри, не между)
радиус плитки            26
радиус вложенного        18     (= 26 − 8)
радиус нажимаемого       капсула (999)
минимальная цель         44pt, для частого действия 56pt, шаг между целями ≥ 8pt
```

- Плитки строятся `VStack(spacing: 10)` + `.padding(10)`, ряд из двух — `HStack(spacing: 10)`, обе `.frame(maxWidth: .infinity)`.
- Тени нет ни под одной плиткой. Обводка — только на стекле.
- `ConcentricRectangle` / `.rect(corners: .concentric(...))` **не применяем**: ни одна плитка не касается края экрана (везде шов 10), концентричность не от чего считать, а радиус угла корпуса ≈ 55 сделает мелкие плитки шарами. Фиксированные 26 / 18 / капсула — осознанно, и это единственные три радиуса в приложении (сейчас их семь: 12/13/14/16/18/20/22).
- Правило бенто: **в столбик не идут больше двух плиток одного размера подряд.** Поэтому «мелкие парами» чередуются с широкими.

### 2.4. Стекло и затемнение

Стекло применяется в двух случаях и больше нигде:

1. **Поверх фотографии.**
2. **Поверх прокручивающегося содержимого** — закреплённая верхняя полоса и нижняя кнопка. Это то, что стекло умеет: показать, что под ним что-то едет.

Статичная карточка на плоском фоне стекло не получает никогда — размывать нечего.

```swift
// Плитка (заменяет GlassCard)
struct Tile: ViewModifier {
    var fill: Color = Brand.tile
    func body(content: Content) -> some View {
        content.padding(20)
            .frame(maxWidth: .infinity, alignment: .leading)
            .background(fill, in: .rect(cornerRadius: 26))
    }
}

// Стекло над фото / над прокруткой
.glassEffect(reduceTransparency ? .identity : .clear, in: .rect(cornerRadius: 26))
.background(.black.opacity(reduceTransparency ? 0.85 : 0.30), in: .rect(cornerRadius: 26))
.overlay { RoundedRectangle(cornerRadius: 26).strokeBorder(
    .white.opacity(contrast == .increased ? 0.9 : 0.35),
    lineWidth: contrast == .increased ? 1 : 0.75) }
```

Затемнение под текстом на фото — **обязательный отдельный слой**, не часть маски:
`LinearGradient(.clear → .black.opacity(0.55))` от середины к низу, поверх — при необходимости `.black.opacity(0.30)` сплошной под самой строкой. Проверять на самом светлом участке кадра, не на среднем.

`glassEffect` ставится **после** модификаторов внешнего вида. Стекло по стеклу не вкладывать. `.drawingGroup()`, `.blur`, `ImageRenderer` над предком стекла — запрещены: стекло выродится в плоский фрост.

### 2.5. Движение

```
переключение периода     .spring(response: 0.3, dampingFraction: 0.8) + matchedGeometryEffect
обновление чисел         .snappy(0.45) + .numericText(value:)
нажатие кнопки           scale 0.98, .spring(0.25, 0.7)
зелёная точка            .easeInOut(1.1).repeatForever
```

`accessibilityReduceMotion` гасит **всё три** вручную (система сама не гасит ни `numericText`, ни `repeatForever`, ни пружину переключателя — сейчас погашено только первое). Первая загрузка — без анимации; прокрутка разрядов от нуля читается как индикатор загрузки.

Тактильность: `.success` при записи машины, `.impact(.rigid)` при открытии/закрытии смены, `.warning` при подтверждении отмены. Сейчас нет ни одной.

## 3. Экран владельца «Այսօր»

Сверху вниз. Ширина везде полная, кроме явно указанных пар.

### 0. Закреплённая верхняя полоса — `safeAreaInset(edge: .top)`

- Слева: **переключатель периода**, капсула, три сегмента `Այսօր / Այս ամիս / Անցյալ ամիս`, высота 44, стекло `.regular` над прокруткой, подсветка выбранного — `trackOn`, пружина и `matchedGeometryEffect` сохраняются.
- Справа: круглая кнопка 44 — `arrow.clockwise`, во время загрузки крутится. Она же и есть видимый признак «идёт запрос».
- `.scrollEdgeEffectStyle(.soft, for: .top)`.

Фиксация решает слабое место: сейчас единственный орган управления экраном уезжает вверх и до него надо скроллить обратно.

### 1. Плитка-герой (грейп, во всю ширину, ~200pt)

```
┌──────────────────────────────────────────┐
│ 1 — 7 օգոստոսի                    tag    │  белый 0.72
│ Այսօր ձեզ մնում է                 body   │  белый 0.85
│                                          │
│ 184 200 ֏                       figure   │  белый, 52pt black rounded
│                                          │
│ Մեկ շաբաթ առաջ այս ժամին                 │  body, белый 0.85
│ 12 400 ֏ · +6 500 ֏                      │
└──────────────────────────────────────────┘
```

- Дата стоит **над** заголовком как `tag` — она обязательна всегда, включая «сегодня», и берётся из `summary.to`, а не из `Date()`.
- Порядок строки сравнения не меняется: с чем сравнили → сколько было → на сколько разошлось. Знак ± обязателен. Драмы, не проценты. Молчит при `count == 0` и при `|diff| < 100` — тогда строки просто нет и плитка становится ниже.
- **Убыток меняет цвет плитки, а не только знак.** `profit < 0` → заливка `charcoal #2A2A2C`, `figure` цветом `warnOnDark`, заголовок «Այսօր մինուսի մեջ եք». Значение по `abs()` — но тогда **и в лестнице тоже по `abs()` с той же подписью**, чтобы два места не расходились. Красного нет: красный в продукте значит «удалить».
- Фотографии в шапке **нет**. Обоснование в §5.
- Мета-строка (дата · машины · единица · средний чек) **разбирается**: дата ушла в `tag`, машины и средний чек — в блок 2. Четыре факта 13-м кеглем белым 0.75 поверх градиента — самый нечитаемый текст экрана, и в нём стоит второй по важности показатель.

### 2. Пара мелких плиток (светлые, 50/50, ~104pt)

| `Մեքենաներ` | `Միջին չեկ` |
|---|---|
| `23` figureS, ink | `8 000 ֏` figureS, ink |
| `tag` = `unitOne` с сервера | `tag` = «մեկ մեքենային» |

Тёмный текст на белом — 16:1, самая читаемая пара на экране. Именно сюда, а не в подпись на градиенте, переезжает счётчик машин.
При `stats.count == 0` плитки остаются с «0» — здесь ноль честный, это факт, а не заглушка.

### 3. Плитка «Հերթափոխին» (светлая) — только когда кто-то есть

- Заголовок плитки: `head` «Հերթափոխին» + зелёная пульсирующая точка 10pt с ореолом `shadow(color: .green.opacity(0.6), radius: 6)` и обязательной текстовой подписью рядом. Точка никогда не единственный носитель смысла.
- Строки, по одной на человека, высота 56: **круг 40 с инициалом** цветом `person(name)` → имя (`body semibold`) → `Spacer(minLength: 12)` → «09:40-ից» (`tag`, mono).
- Время выхода форматируется **с явным `tenant.timezone` и локалью `hy_AM`**. Сейчас берётся зона устройства — владелец в поездке видит смену, начатую в шесть утра.
- Блок стоит выше лестницы: «кто сейчас на площадке» — вопрос текущей минуты, лестница — вопрос «когда захочу разобраться». Порядок сейчас обратный.
- «На смене» считается от начала сегодняшнего дня независимо от периода — на плитке это подписано `tag`-строкой «հենց հիմա», чтобы блок не читался как часть выбранного месяца.

### 4. Плитка «Ձեր փողը» — лестница прибыли (светлая)

Заголовок внутри плитки, `head`. Сейчас это единственный крупный блок без заголовка.

```
Հասույթ                              248 000 ֏
▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬▬
− Աշխատավարձ                          62 000 ֏
▬▬▬▬▬▬▬
  Աշխատավարձից հետո                  186 000 ֏
− Ծախսեր                               1 800 ֏
   Միանվագ 800 · ամսականից օրվա բաժինը 1 000
▬
──────────────────────────────────────────────
Ձեզ մնում է                          184 200 ֏   head, ink
```

- Знак «−» перед подписью, не внутри числа.
- Полоски: длина `value / revenue`, общий левый край, высота 3, минимум 2pt, clamp 1, при `revenue == 0` → 0.
- Расшифровка расходов только при `expenses > 0`, каждая часть только при значении > 0.
- **Итог набирается `head` (20pt), а не 26pt, и цветом `ink`** — цвет включается только при убытке (`warn`). Это гасит слабое место «прибыль напечатана дважды разным кеглем и цветом»: в герое число — картинка, здесь — итог столбика. Подпись у них дословно одна и та же («Ձեզ մնում է» / «Մինուսի մեջ եք»), чтобы читалось «это оно», а не «второе число».
- Слово «շահույթ» не появляется нигде.

### 5. Плитка «Ժամերով / Օրերով» — график (светлая) — только при `series.count > 1`

- Полосы высотой 72pt, скруглённые сверху, ширина считается от доступной: `pitch = (width − 40) / n`, полоса `pitch − 3`, минимум 2pt. На 30 днях это ≈ 7pt вместо нынешних слепых полосок.
- Три состояния сохраняются: ноль — риска цветом `line`, пик — `grapeFill`, остальные — `grapeFill` 0.28.
- **Ось выносится из полос в отдельный ряд под ними** и содержит ровно три подписи: первая точка, пик, последняя. Прореживание «каждая третья» уходит вместе с пустыми `Text`-нодами и линейным поиском индекса на каждый столбик.
- Пик подписан цифрой «առավելագույնը X» — остаётся, это единственный масштаб.
- **Касание по полосе** показывает над ней капсулу «16:00 · 34 000 ֏» на 2 секунды. Сейчас значение столбика не узнать никак.
- Метка по-прежнему режется из строкового ключа `"2026-07-29 16"`: часы — суффикс, дни — символы 8–9. Дата остаётся строкой, не `Date`.

### 6. Плитка «Վճարումներ» — дуга с рисками (светлая)

Единственный дуговой индикатор в приложении, и он отвечает на вопрос, ради которого блок существует и на который сейчас не отвечает: сколько денег прошло мимо кассы.

- `Canvas`, 60 рисок, sweep 260°, начало снизу-слева. Каждая риска покрашена цветом того способа оплаты, чью долю она попала: `cash → good`, `card → grapeFill`, `transfer → grapeFill 0.5`, прочее → `muted`. Сегменты идут по убыванию, минимум одна риска на способ.
- В центре: `figureS` «62 %» и `tag` «Կանխիկ». Процент здесь уместен — это доля от целого, а не рост от базы.
- Под дугой — строки «круглая иконка 34 · подпись · сумма справа», по одной на способ, `VStack`, а не `HStack`: нынешняя легенда переполняется на трёх-четырёх способах.
- Неизвестный ключ оплаты не ломает экран: `muted`, `circle.fill`, ярлык — сам ключ.
- В `Canvas` **каждая локальная переменная аннотируется явно** (`let cx: Double = …`), иначе солвер типов не собирает выражение. Весь индикатор — один `accessibilityElement` со значением: `Canvas` не отдаёт доступность по частям.
- Плитка исчезает при пустом периоде.

### 7. Плитка «Հոսք» — лента (светлая, последняя)

Строка, высота 64:

```
14:32 │ ●Դ  10 AB 345                       4 000 ֏   ›
      │     Դավիթ · Թափք · ▣               նրան 1 000
```

- **Время появилось.** `createdAt` приходит с сервера и сейчас не показывается ни в одной строке, хотя лента отсортирована по нему.
- Круг 28 с инициалом цветом `person(name)`; цвет всегда рядом с именем, никогда вместо.
- Способ оплаты — значком, не словом.
- Доля исполнителя считается по снимку процента внутри записи; строка «նրան X» скрыта при `staffPercent == 0`.
- `clientKey == nil` → «—», `staffName == nil` → «—» и `person("")` даёт `muted`, а не случайный цвет.
- **Отмена получает видимый афорданс**: свайп влево → красная кнопка «Չեղարկել». `contextMenu` остаётся для тех, кто привык. Alert подтверждения не меняется: клиент и сумма в сообщении, «Ոչ» / «Չեղարկել», затем `POST cancel` и безусловный reload.
- **Строка тапается** и ведёт в карточку клиента (она в продукте уже есть). Шеврон `›` `faint`. Экран перестаёт быть тупиком.
- В подвале плитки при 100 записях: «Ցուցադրված են վերջին 100 գրանցումը» — сейчас список просто обрывается и спорит со счётчиком машин в герое.

### Состояния экрана владельца

| Состояние | Что на экране |
|---|---|
| **Загрузка** (`summary == nil`) | Все плитки стоят на местах. Вместо каждого числа — капсула `line`, ширина 140 / 72 / 96, высота = кегль × 0.72, радиус 6. **Ни одного нуля и ни одной сегодняшней даты.** Без мерцания: шиммер — это анимация, то есть нагрев и работа против Reduce Motion. Крутится только кнопка в верхней полосе |
| **Ошибка при наличии данных** | Плитки остаются. Сверху щита появляется угольная плитка высотой 56: «Կապ չկա · տվյալները 14:20-ի դրությամբ» + круглая кнопка ↻. Сейчас сбой сети стирает свежие данные с экрана — во дворе мойки это выглядит как их потеря |
| **Ошибка без данных** | Ошибка заменяет всё, кроме верхней полосы. Тексты: «Կապ չկա։» / «Սերվերը չպատասխանեց» + кнопка «Կրկնել». **Сырой дамп ошибки декодирования уходит в лог, на экран — «Տվյալները չհաջողվեց կարդալ»**; для отладки остаётся долгое нажатие на текст → копировать подробности |
| **Пусто** (`summary != nil`, лента пуста) | Герой, две мелкие плитки и лестница с нулями остаются. Вместо ленты, графика и оплат — одна плитка `ContentUnavailableView`: иконка, «Դեռ տվյալներ չկան», «Առաջին մեքենան կհայտնվի այստեղ». Щит из трёх плиток обязан выглядеть законченным — поэтому сетка одноколоночная, а не жёсткое бенто |

## 4. Экран мойщика «Հերթափոխ»

Сцена: одна рука, мокрые пальцы, солнце, плохая связь. Всё, что нужно нажимать часто, — не меньше 56pt и в нижней трети. Всё, что сообщает о неполадке, — не мельче 15pt.

### 0. Верхняя полоса (без плитки, текст прямо на шве)

- Слева: «Բարի լույս, Դավիթ» — `body`, `mutedOnDark`. Приветствие остаётся (единственное место, где продукт обращается к человеку), но перестаёт занимать плитку и уступает место числу.
- Справа: круглая кнопка 44, `person.crop.circle` → лист профиля. **Кнопка выхода `power` из тулбара убирается**: сейчас она разлогинивает без подтверждения с рабочего экрана, а обратный вход стоит телефона и PIN мокрыми руками. Выход живёт внутри листа и спрашивает.

### 1. Плитка-герой (грейп, ~190pt)

```
Քո վաստակը այսօր                          tag,  белый 0.72
21 000 ֏                               figure,  белый
ներառյալ 2 չուղարկված                     tag,  lime  ← только когда очередь не пуста
12 մեքենա · 84 000 ֏ · քո 25%             body, белый 0.85
```

- Выбор числа по `takesShare = percent > 0` сохраняется: у владельца, записывающего самому, — выручка, а не «твой заработок: 0 ֏».
- **Очередь двигает число.** Клиент уже воспроизводит серверную формулу доли и округление (`API.swift:196-215`), значит вклад непосланных записей считается точно так же и прибавляется к `figure`, а под числом стоит лаймовый `tag` «ներառյալ N չուղարկված». Сейчас человек моет пять машин без связи и видит неподвижную цифру — единственный отклик на его работу — серая строчка 13.5pt.
- Подпись «машины · выручка · քո N%» сохраняется дословно: без неё цифру нечем проверить.

### 2. Плитка статуса смены (~92pt) — вместо системного `Toggle`

**На смене** (светлая плитка):
`● Հերթափոխին եմ` (зелёная пульсирующая точка 10 + подпись, `head`) · «09:40-ից» (`tag`) — справа капсульная кнопка «Ավարտել», высота 48, ширина ≥ 120, заливка `tileSoft`, текст `ink`.

**Вне смены** (угольная плитка `charcoal`):
`○ Հերթափոխից դուրս` (`inkOnDark`) — под ней канон-кнопка во всю ширину: лаймовая капсула высотой 56, текст «Սկսել հերթափոխը» слева, чёрный круг 48 со стрелкой вплотную к правому краю (падинги 24 слева / 6 справа / 6 сверху-снизу).

Нынешняя мишень — `Toggle` ~51×31 в углу карточки: самая маленькая интерактивная цель экрана, от которой зависит вся запись, и случайное касание сразу открывает модалку с числовым полем. Новая мишень — 48–56pt и разные по виду состояния.

Оптимистичное переключение с честным откатом сохраняется. Добавляется офлайн-путь: **`onShift` пишется на диск рядом с очередью**, и при отсутствии связи смена открывается локально, а запрос уходит вместе с очередью. Иначе мойщик в подвале не может ни встать на смену, ни записать машину — офлайн-очередь недостижима ровно тогда, когда она нужна.

### 3. Пара мелких плиток (светлые, 50/50, ~104pt)

| `Կանխիկ քեզ մոտ` | `Հերթափոխին` |
|---|---|
| `34 000 ֏` figureS | `4 ժ 20 ր` figureS |

`cashSoFar` и `openedAt` приходят с сервера и сегодня видны только в момент закрытия смены. Наличные человек носит в кармане весь день, и сверить их не с чем. Длительность считается от `openedAt` и обновляется при каждом reload — не по таймеру (иначе она врёт между тиками; поэтому же у владельца показывается время выхода, а не длительность).

### 4. Плитка очереди — только когда очередь не пуста (угольная)

«2 գրանցում սպասում է կապին», `inkOnDark`, `body` — тон спокойный, без тревоги: запись сделана и не пропадёт. Справа круглая кнопка 44 `arrow.clockwise`.

### 5. Плитки отказов — по одной на отвергнутую запись (светлая, левый край `warn` 3pt)

- Номер машины — `head`.
- Причина — **человеческим текстом**, не кодом. Обязательная таблица перевода; латинский `SHIFT_REQUIRED` посреди армянского экрана человеку, который по этой строке решает «повторить или удалить», не говорит ничего:

| Код | Текст |
|---|---|
| `SHIFT_REQUIRED` | Հերթափոխը փակ էր |
| `SUBSCRIPTION_EXPIRED` | Բաժանորդագրությունը լրացել է |
| `HTTP 5xx` / прочее | Սերվերը չընդունեց |

- Кнопки **в разных строках, а не встык**: «Կրկնել» — лаймовая капсула во всю ширину; «Հեռացնել» — текстовая кнопка ниже, с отступом 24 и с alert-подтверждением. Сейчас две кнопки одного размера и стиля стоят вплотную, и один мазок мокрым пальцем стирает работу навсегда.

### 6. Плитка «Վերջինները» — лента смены (светлая)

Строка высотой 60: `14:32` (`tag`, mono) · номер машины (`body semibold`) · услуга и значок оплаты (`body`, `muted`) · сумма справа (`head`, mono).

- Номера машины в ленте сейчас нет — «записал ли я вон ту синюю» проверить нельзя, хотя в карточке очереди номер как раз показан. Если `API.ShiftOrder` не отдаёт `clientKey`, это требование к серверу, а не к вёрстке.
- Касание строки → лист «Ուղղել»: изменить способ оплаты, отменить запись. Ошибка в оплате при записи одним касанием без подтверждения сегодня неисправима, а промах мокрым пальцем — норма.
- «pass / Աբոնեմենտ» показывается ярлыком и значком, хотя создать её в iOS нельзя.

### 7. Закреплённая нижняя полоса — `safeAreaBar(edge: .bottom)`

- **На смене:** лаймовая капсула высотой 64 во всю ширину минус шов, текст «Գրանցել մեքենա» слева, чёрный круг 48 со стрелкой справа. Заливка сплошная, не стеклянная: стекло берёт цвет от подложки, а единственное действие экрана обязано выглядеть одинаково всегда.
- **Вне смены:** капсула угольная, неактивная, над ней `tag` «Գրանցելու համար միացրեք հերթափոխը». Отказ показан кнопкой, а не окошком, и причина содержательная.
- `safeAreaBar`, а не `safeAreaInset`: он продлевает scroll edge effect, и лента не обрезается под кнопкой.

### Три касания: что меняется в `OrderFlowView`

Экран записи не перерисовывается, но два его дефекта — часть этого редизайна, потому что они про руку и солнце:

1. **Шаг оплаты переворачивается.** Три способа оплаты — крупные капсулы 64pt внизу, в зоне большого пальца. «Հետ» уезжает в круглую кнопку 44 в левый верхний угол. Сейчас самое частое действие требует перехвата телефона, а самое редкое достаётся пальцу само.
2. **`.numberPad` получает тулбар «Պատրաստ է»** на скидке и на сумме сдачи. Сейчас на шаге оплаты убрать клавиатуру можно только записав машину.
3. Успех: галочка 1.4 с **плюс `.notification(.success)`**. Зрение — самый ненадёжный канал в этой сцене.
4. После сканера номер не проглатывает шаг узнавания: `step = 1` ставится **после** ответа `lookup` либо экран узнавания показывается поверх на 1 с. Быстрый путь не должен отменять главную ценность медленного.
5. Номер нормализуется на клиенте так же, как на сервере (`trim`, `uppercase`, **удаление пробелов**) — иначе «12 AB 345» из сканера и «12AB345» с клавиатуры становятся двумя клиентами, и «был у нас 7 раз» перестаёт появляться.
6. `lookup` получает дебаунс 350 мс и защиту от гонки по `loadID` — такую же, как в `reload`.

Перечисляю отдельно, чтобы они не потерялись между вёрсткой и логикой: холодный старт без связи выбрасывает на экран входа и делает очередь невидимой (`Session.swift:40-51`); закрытие смены не кладётся в очередь и теряет введённую сумму; локальной защиты от двойной записи одного номера нет; индикатора «нет связи» на экране нет вовсе, хотя `Connectivity` создан в `TetrApp`. Первые три — про деньги, и ни одна плитка их не исправит.

## 5. Изображения

### Решение: на рабочих экранах фотографии нет

Не потому, что она плохая, а потому что она стоит 35–40 % первого экрана и не несёт ни одного бита данных. Владелец открывает приложение между делами ради одной цифры; мойщик — сорок раз в смену мокрыми руками. Фото в шапке отодвигает и цифру, и кнопку. Плюс продукт мультиниш: любой узнаваемый кадр придётся менять на каждой новой нише.

Роль «фотографии как содержимого» на этих двух экранах играет **`figure`** — одно большое число на плитку. Это прямо записано в системе лендинга: число работает как картинка.

### Где фотография всё-таки нужна — четыре места

| Место | Кадр | Как ложится |
|---|---|---|
| `LoginView` | **Снимок 1**: одна кисть, крупный кроп по запястье, телефон в рабочем хвате, большой палец на экране. Ни лиц, ни тел, ни второй руки, ни одной машины | Верхняя плитка высотой `44svh`, `scaledToFill`, `clipped()` **до** маски, низ растворяется маской `LinearGradient(black 0 → black 0.55 → clear 1)`. Поверх — стеклянная карточка с формой входа. Обязательный отдельный слой затемнения под текстом |
| `OnboardingView` | Тот же снимок 1 | Плитка 12 колонок, стекло с одной фразой |
| Смена до открытия (`onShift == false`, машин нет) | **Снимок 2**: та же кисть, другой ракурс — палец нажимает, ладонь чуть развёрнута | Плитка высотой 180 между приветствием и плиткой статуса. Как только смена открыта — плитка исчезает навсегда до следующего утра |
| Владелец, пустой период | Фотографии нет | `ContentUnavailableView` с SF Symbol. Кадр «пустая площадка утром» намертво привязал бы продукт к мойке |

### Как снимать и генерировать

- **Сюжет:** руки за работой. Мойщик, барбер, механик, клинер, врач — все делают что-то руками и все записывают это в телефон. Рука с телефоном показывает механизм продукта, а не отрасль.
- **Кадрирование:** кроп по запястье, кисть заполняет 70–80 % кадра, предмет в рабочем хвате, точка съёмки чуть выше кисти. Ни лиц, ни тел, ни фирменной одежды, ни логотипов, ни номерных знаков.
- **Свет:** мягкий, ровный, один деликатный блик на корпусе телефона. Жёсткая тень уводит кадр в мрачное и ломает светлую систему.
- **Фон:** для выреза — абсолютно плоская мята `#C8DCD1`, без градиента, без пола, горизонта, тени и отражения. Для полного кадра — высветленный, без тёмных углов.
- **Цвет:** холодный нейтральный или мятный, без посторонних тёплых пятен, чтобы лайм остался единственным горячим местом на экране.
- **Промпт всегда называет пять вещей:** предмет, материал, свет, фон, ракурс. Для выреза добавляется `completely flat pale sage mint #C8DCD1 background, absolutely uniform, no floor, no horizon, no cast shadow, no reflection`.
- Каждый сгенерированный кадр помечается синтетическим в `public/shots/README.md`. Отзывы, логотипы клиентов и цифры «N моек уже считают» не генерируются ни в каком виде.
- Все декоративные изображения — `.accessibilityHidden(true)`.
- Готовить в 2× и 3×, `@2x` ≥ 1600px по большей стороне; HEIC в ассетах.

### Иконки

Кастомных иконок не рисуем: SF Symbols покрывают всё, а армянский `֏` уже в шрифте. Полный список того, что нужно, — двенадцать символов:

`arrow.clockwise` (обновить) · `arrow.up.right` (круг на шве) · `arrow.right` (круг в капсуле) · `chevron.left` (назад в потоке записи) · `chevron.right` (вглубь из строки ленты) · `xmark` (убрать услугу) · `banknote` / `creditcard` / `arrow.left.arrow.right` / `ticket` (наличные, карта, перевод, абонемент) · `camera.viewfinder` (сканер) · `person.crop.circle` (профиль).

Иконки, привязанной к мойке, на экранах нет ни одной — включая плитку «Մեքենաներ», где значок машины сломался бы на первой же не-мойке. Там иконки нет, есть `tag` со словом `unitOne` с сервера.

Каждый `Image(systemName:)` внутри кнопки получает `.accessibilityLabel` — сам по себе VoiceOver не говорит ничего. Круглая иконка внутри строки статистики + подпись + значение объединяются в один элемент `.accessibilityElement(children: .combine)`.

## 6. Что не делать

1. **Анимированный `MeshGradient` в `TimelineView` как фон.** 30–60 перерисовок в секунду весь срок жизни экрана, который открывают на пять секунд между делами. Греет телефон, не сообщает ничего, и HIG прямо запрещает стекло поверх полноэкранного задника.
2. **Фотография во весь фон экрана и текст поверх неё без плитки.** На светлых участках кадра белый текст пропадает, и это не ловится ни на одном тестовом снимке — ловится на мокром экране под солнцем.
3. **Стекло на статичной карточке поверх плоского фона.** Размывать нечего; получается мутная плашка, которая ещё и меняет вид при скролле. Сейчас так сделаны пять из семи блоков владельца.
4. **Стекло на главной кнопке.** Единственное действие экрана обязано выглядеть одинаково всегда.
5. **Стекло по стеклу, тень поверх стекла, `.drawingGroup()` над стеклом.** Первое не сэмплится, второе даёт двойную кромку, третье растрирует задник и убивает эффект.
6. **Дуга-прогресс без знаменателя.** У прибыли нет цели, у смены нет плана. Дуга, показывающая «сколько-то из ничего», — украшение с видом данных. Единственная честная дуга — доля наличных.
7. **Ряд из пяти круглых кнопок-иконок как навигация.** У владельца два действия, у мойщика одно. Ряд кружков придётся заполнить выдуманными.
8. **Круглые кнопки «назад» и «домой» в верхних углах.** В приложении есть таб-бар и `NavigationStack`; вторая навигация поверх первой — это не референс, это дубль.
9. **Отсчёт большого числа вверх при появлении.** Прокрутка разрядов от нуля читается как индикатор загрузки. `numericText` — только при изменении и только вне Reduce Motion.
10. **Капс для армянских подписей.** Армянский капс читается хуже латинского; в референсе капс работает на английском.
11. **Зелёная точка без подписи.** Провал WCAG 1.4.1 и первое, что пропадает на солнце.
12. **Тени под плитками.** Тень в бенто — признак того, что сетке не доверяют. Плитки разделяет шов.
13. **`.ultraThinMaterial` вместо `glassEffect` «ради предсказуемости».** Материал сэмплит иначе и над фото выглядит грязной плёнкой.
14. **Фото под цифрой как «текстура» с прозрачностью 15 %.** Это ровно то, что система запрещает: фотография — содержимое, а не фон.
15. **Красный для убытка.** Красный в продукте значит «удалить».
16. **Второе лаймовое пятно на экране.** Первое обесценивается мгновенно.
17. **Мята и грейп через шов.** Два насыщенных цвета встык дребезжат; между ними всегда светлая, угольная или фотоплитка.
18. **Чистый чёрный.** Ни пикселя: шов тёплый уголь `#1C1C1E`.

## 7. Порядок сборки

Каждый шаг проверяется на **пяти конфигурациях**: iPhone SE (320pt ширина) и iPhone 17 Pro Max; светлая и тёмная тема; Dynamic Type `accessibility3`. Плюс отдельно: Reduce Motion, Reduce Transparency, Increase Contrast, Liquid Glass в режиме Tinted (iOS 26.1).

**Шаг 1. Токены.** `Theme.swift`: добавить `seam / tile / tileSoft / charcoal`, набор `*OnDark`, `person(_:onDark:)`; поменять `heroGradient`; `screenBackground()` на `seam`; ввести `Tile` и оставить `GlassCard` только под фото; `LimeButton` → капсула + `@ScaledMetric` + чёрный круг со стрелкой.
*Проверка:* приложение собирается, старые экраны выглядят как раньше, кроме фона; ни один текст не пропал в тёмной теме.

**Шаг 2. Шкала кеглей.** Ввести пять `@ScaledMetric` и заменить `.font(.system(size:))` на экране владельца. Метрики поедут — вёрстка пересобирается вместе с этим, а не после.
*Проверка:* на `accessibility3` ни одна строка не обрезана многоточием; `figure` не выходит за плитку.

**Шаг 3. Щит владельца из заглушек.** Семь плиток нужного размера и цвета с фиктивными данными, без графиков и дуги. Шов 10, падинг 20, радиус 26.
*Проверка глазами:* три разных размера плиток, ни одной тени, ни одной обводки на сплошной плитке, шов у края равен шву между плитками.

**Шаг 4. Данные владельца.** Герой, две мелкие плитки, смена, лестница, лента. Все `nil`-фолбэки и все правила молчания переносятся дословно.
*Проверка:* пустой период (три плитки), убыток (плитка становится угольной), `previous.count == 0` (строки сравнения нет), 100 записей (подпись об обрезке), прошлый месяц (даты диапазона в `tag`, а не сегодняшняя дата).

**Шаг 5. Состояния.** Скелеты загрузки, полоса «на 14:20» поверх кеша, человеческие тексты ошибок, `ContentUnavailableView`.
*Проверка:* включить авиарежим на холодном старте и после успешной загрузки — в первом случае ошибка вместо всего, во втором цифры остаются с пометкой. Ни одного нуля до ответа сервера.

**Шаг 6. Новые формы.** График с вынесенной осью и касанием, дуга с рисками.
*Проверка:* 400 точек не роняют скролл; `Canvas` собирается (все локальные `let` аннотированы `Double`); VoiceOver читает дугу как один элемент со значением; при `revenue == 0` нет NaN-геометрии.

**Шаг 7. Экран мойщика.** Герой, плитка статуса, пара мелких, очередь и отказы, лента, нижняя закреплённая кнопка.
*Проверка:* кнопка записи достаётся большим пальцем на 6.9″ без перехвата; мишень смены ≥ 48; «Հեռացնել» не ближе 24pt к «Կրկնել»; коды отказа не видны нигде.

**Шаг 8. Офлайн и рука.** Локальное `onShift`, вклад очереди в `figure`, тулбар над `.numberPad`, тактильность, дебаунс `lookup`, нормализация номера.
*Проверка:* авиарежим → встать на смену → записать три машины → число выросло и подписано «ներառյալ 3 չուղարկված» → связь → число не изменилось после досылки. Расхождение здесь означает, что клиентская формула доли разошлась с серверной.

**Шаг 9. Доступность.** Reduce Motion гасит пружину, точку и прокрутку разрядов; Reduce Transparency переводит стекло в `.identity` и поднимает затемнение до 0.85; Increase Contrast поднимает обводку до 1pt / 0.9.
*Проверка:* VoiceOver проходит оба экрана сверху вниз без «круг, Բաց է» и без немых иконок.

**Шаг 10. Ошибки данных, которые видно через дизайн.** Верхняя граница в `getFeed` для прошлого месяца, `tenant.timezone` во времени выхода, переименование `revenue` → `profit` в `OwnerView`.
