# Tetrin: спецификация анимации марки

## Фаза 1. Источник и бриф

**Источник.** Марка в продукте живая, не картинка: `components/wordmark.tsx` набирает
«TETR» шрифтом Unbounded Black (13px, разрядка 0.18em, цвет `--foreground #1b1726`),
«IN» вывороткой `#ffffff` на грейповой плашке `--primary #441887` со скруглением 3px
(паддинг 2×4px, отступ слева 2px). Эталонный растр снят с точной реплики продакшен
разметки в Chrome при DPR 8: `source.png` 880×336, фон белый. Позиции пера каждой
буквы измерены Range API, базовая линия 208px подтверждена двумя независимыми
способами (чернила плоских оснований T/E/R и canvas-метрики шрифта).

**Семантические части (актёры).**

| id | часть | роль в хореографии |
|---|---|---|
| `#t1 #e #t2 #r` | буквы TETR, чернила | каскад: слово собирается |
| `#badge` | плашка + выворотка, одно целое | штамп: опускается на своё место |
| `#plaque` | грейповый прямоугольник | лицо штампа |
| `#in` (`#i #n`) | белые I, N | оттиск, едет вместе со штампом |

**Личность движения: «собранный, весомый, точный».**
Выведена из самой марки и продукта: Unbounded Black это широкий геометрический
гротеск с индустриальными срезами (engineered motion), продукт по DESIGN.md
«рабочий инструмент: плотный, без теней и украшений» (serious, low-mid energy),
а конструкция знака сама подсказывает сюжет: последние две буквы имени взяты в
плашку. Отсюда драматургия: слово прибывает, печать ставится.

**Пресет: Trustworthy / Professional** с одним взвешенным отступлением.
По осям: энергия ниже средней, тон серьёзный. Пресет запрещает сквош, но вес
штампа должен читаться, поэтому плашке разрешена компрессия 3% на один удар
(volume-preserving, восстановление мягкое). Буквам никакого сквоша, приземление
точно в позицию без позиционного овершута.

**Контекст использования.** Витрина и оболочки кабинета показывают марку в шапке:
reveal при загрузке страницы (один раз), плюс микровзаимодействия. Showcase несёт
полный splash-вариант 1200мс; для шапки та же хореография, тот же голос.

## Фаза 2. Геометрия

- Уровень сложности: аналитические кривые, взятые напрямую из продакшен woff2
  (fontTools, upem 1000, масштаб 0.104). Никакой трассировки. Плашка: один
  `<rect rx=24>`.
- Разрядка, кернинг, позиции: измерены в браузере, не вычислены.
- Плашка задана по фактически нарисованному боксу [536, 104, 248, 136]:
  Chrome прибивает окраску фона к целым CSS-пикселям (getBoundingClientRect
  давал дробные 536.75..781.0, краска легла на 536..784 жёсткой кромкой).
  Это осознанный выбор в пользу контракта финального кадра с растром.
- Итерации: 01 глифы из шрифта (IoU 0.9874, вся дельта на кромках плашки),
  02 плашка по нарисованному боксу: **IoU 0.9974, src_only 18px, render_only
  95px** (уровень сглаживания кромок). Гейт гладкости пройден по построению:
  контуры из шрифта, зум-кропы `zoom_R.png`, `zoom_corner_src_vs_render.png`
  без ступенек. svg_path_audit не гонялся: кривые канонические из шрифта,
  ручной подгонки не было.

## Фаза 3. Хореография

**Сюжет (staging, порядок чтения).** Пустой холст держит удар 90мс. Буквы T E T R
встают из-под базовой линии слева направо внахлёст. Пока R доводится, плашка
проявляется приподнятой над своим местом, приподнимается ещё чуть (замах) и
падает штампом. Удар: компрессия 3%, волна веса прокатывается по буквам справа
налево затухая. Всё замирает в выверенном статике к 1200мс.

**Форма таймлайна** 20:50:30 с перекрытиями: замах 0..240 (холст + медленные
старты первых букв), действие 240..840 (каскад букв, появление и падение
штампа, удар 810), довод 840..1200 (компрессия, волна, успокоение).

**Один общий такт.** Все элементы: `animation: … 1200ms linear both`, фазовые
сдвиги внутри keyframes процентами, изинги литеральными cubic-bezier в каждом
сегменте (ловушка var() в keyframes задокументирована в скилле).

**Токены** (соответствие дизайн-системе продукта):

```css
--p2m-duration: 1200ms;
--p2m-ease-soft: cubic-bezier(0.2, 0, 0, 1);    /* = --ease-out-soft продукта */
--p2m-ease-rise: cubic-bezier(0.16, 1, 0.3, 1); /* = --ease-out-slow продукта */
--p2m-ease-drop: cubic-bezier(0.55, 0, 0.85, 0.36); /* разгон штампа, новый */
```

**Таймлайн** (мс от 0, проценты от 1200):

| актёр | сегмент | мс | % | изинг |
|---|---|---|---|---|
| t1 | подъём y+40→0, fade | 90..480 | 7.5..40 | rise |
| e | подъём | 160..550 | 13.33..45.83 | rise |
| t2 | подъём | 230..620 | 19.17..51.67 | rise |
| r | подъём | 300..690 | 25..57.5 | rise |
| badge | проявление приподнятым y−52 | 560..636 | 46.67..53 | soft |
| badge | замах: y−52→−64, scale 1.18→1.22 | 636..690 | 53..57.5 | soft |
| badge | падение y−64→0, scale 1.22→1 | 690..810 | 57.5..67.5 | drop |
| badge | компрессия scaleY .97, низ прижат | 810..880 | 67.5..73.33 | soft |
| badge | восстановление до 1 | 880..1010 | 73.33..84.17 | rise |
| r | волна вниз 6ед и назад | 810..972 | 67.5..81 | soft/rise |
| t2 | волна 4.5ед | 840..1002 | 70..83.5 | soft/rise |
| e | волна 3ед | 870..1032 | 72.5..86 | soft/rise |
| t1 | волна 1.5ед | 900..1062 | 75..88.5 | soft/rise |

Стаггер букв 70мс = 18% от 390мс подъёма (правило 10..20%). Ни одна пара
актёров не стартует и не останавливается одновременно. Волна затухает по
амплитуде 6/4.5/3/1.5 единиц viewBox (≈4.2/3.2/2.1/1px на экране showcase).

**Принципы.** Staging (порядок чтения: слово, потом печать), Anticipation
(холст 90мс; замах штампа вверх перед падением), Timing (буквы 390мс, штамп
160мс падения: короче и резче, он тяжёлый и падает), Slow In/Out (все сегменты
на кривых продукта), Follow Through & Overlap (стаггер, компрессия, затухающая
волна по буквам), Squash & Stretch (3% плашке, volume-preserving, буквам ноль),
Exaggeration (подъём замаха 6ед: только фокусному биту), Solid Drawing (бейдж
цельный, IN не отделяется; базовая линия букв не плывёт: подъём чисто по Y),
Appeal (сюжет из конструкции самой марки: имя получает печать).

**Атомы** (микроэтюды из тех же частей): наведение «кнопка» (пресс бейджа),
пульс плашки 2.4с (= ритм now-breathe продукта), волна букв, повторный штамп.

**Настройки** showcase: Replay, слоумо, слайдер скорости (живой). QA-хуки
`?t=<ms>`, `?static=1`, `window.__p2mReady`, `#logo-root`.

## Фаза 3. Контроль качества движения: результаты

- Кадры 0..1200 (16 точек, включая окна риска) сняты через `?t=`, стрип
  `outputs/motion_strip.png`, сетки `frames_grid1/2.png` осмотрены: замах
  читается (620 против 690), каскад ступенчатый, ничего не клипается,
  базовые линии не плывут.
- Проба изинга (`probe_motion_continuity.py --probe`): `#t1` на 150/250/350 и
  `#badge` на 700/750/800 совпадают с расчётными кривыми rise и drop
  (на 800мс прогресс 0.716 при линейных 0.917: кривые живые, var() не
  дропнулся).
- Штатный `--ink-sweep 780:900` выдал предупреждение stall+pop: это ложное
  срабатывание эвристики нетто-чернил, заточенной под draw-on, где чернила
  только прибывают. Здесь падение штампа законно уменьшает площадь
  (scale 1.22→1), а сабпиксельный сдвиг букв качает счётчик на ±300px.
  Непрерывность доказана покадровой метрикой изменения
  (`outputs/fit_work/sweep_and_contract.py`): в окнах 520..700 и 700..1000
  скорость изменения без нулевых пауз с последующим скачком; пик 34683
  изменённых пикселей ровно на ударе 810, затем гладкое затухание волны.
- **Контракт финального кадра: PASS.** Same-pipeline `?static=1` против
  `?t=1200`: ровно 0 расходящихся пикселей. Кросс-пайплайн диф с
  `outputs/final_render.png`: mean 0.884, максимум на кромках сглаживания
  (0.985% px), глазами подтверждено `final_vs_frame.png`: геометрия, цвет,
  позиции идентичны.
